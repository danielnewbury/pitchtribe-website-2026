Beginner’s setup guide

From a box of parts to your club’s first notice on the TV. You won’t type a single command. Allow about 30 minutes, most of it waiting for things to download and copy.

The short version

Download the PitchTribe image → copy it to a memory card with Raspberry Pi Imager → put the card in the Pi, plug the Pi into the TV and switch it on → open pitchtribe.local on your phone and choose a password.

What you need

For the screen

  • A Raspberry Pi 5 with 4 GB of memory or more. A Raspberry Pi 4 works too.
  • The official Raspberry Pi power supply for your model (the 27 W USB-C one for a Pi 5). Phone chargers often aren’t powerful enough and cause random restarts.
  • A microSD memory card, 32 GB or bigger. Cards marked A2 are faster. Everything on the card will be wiped.
  • A micro-HDMI to HDMI cable. The Pi has the small micro-HDMI sockets, not full-size ones, so an ordinary HDMI cable won’t fit.
  • A case for the Pi, ideally one with a fan or heatsink.
  • A TV or monitor with a spare HDMI socket, and a mains socket near it.
  • Internet for the Pi: the club’s Wi-Fi name and password, or a network cable to the club router. A cable is more reliable if the router is close.

The parts list on the Buy page has every item with a price.

For setting it up (once)

  • A computer — Windows, Mac, ChromeOS or Linux — that can read a microSD card. Many laptops have a slot; if yours doesn’t, a USB card reader costs a few pounds.
  • A phone, tablet or laptop on the club’s Wi-Fi, to open the dashboard at the end.

You don’t need a keyboard or mouse for the Pi.

Step by step

  1. Install Raspberry Pi Imager on your computer

    Raspberry Pi Imager is the free program that copies the PitchTribe software onto the memory card. Download it from raspberrypi.com/software and install it like any other program.

  2. Download the PitchTribe image

    Go to the latest PitchTribe release and, under Assets, click pitchtribe-rpi-arm64.img.xz. It’s about 1.2 GB, so it may take a few minutes.

    An “image” is simply a complete copy of everything that goes on the memory card: Raspberry Pi’s own operating system with PitchTribe already installed and set up. Don’t unzip it — Imager reads the .xz file as it is.

  3. Copy the image to the memory card

    Put the microSD card in your computer and open Raspberry Pi Imager. It walks you through a few choices:

    1. Device: choose your Pi — Raspberry Pi 5 (or 4).
    2. Operating system: scroll to the bottom of the list, choose Use custom, and pick the pitchtribe-rpi-arm64.img.xz file you downloaded.
    3. Storage: choose the microSD card. Check the size matches your card — whatever you choose here is wiped.

    Imager then offers to customise the card. These settings are worth filling in:

    SettingWhat to put
    HostnameA name for this screen, like bar-tv or clubhouse: small letters, numbers and hyphens only — no capitals or spaces. It becomes the dashboard’s address (bar-tv.local) and the screen’s name in the dashboard. Leave it blank and the Pi is called pitchtribe.
    Wi-FiThe club’s Wi-Fi name and password, exactly as written (they’re case-sensitive). Skip this if you’ll use a network cable.
    LocalisationYour time zone (e.g. Europe/London), so clocks and fixtures show the right time.
    User and SSHOptional. Only needed if you later want to add guest Wi-Fi or update from the command line. If you set them, write the username and password down somewhere safe.

    Then choose Write and confirm. Copying and checking the card takes 5–15 minutes. When Imager says it’s finished, take the card out.

    Imager didn’t offer to customise?

    Some versions of Imager skip the customisation for a file you picked with “Use custom”. The Pi still works, but it won’t know your Wi-Fi, so use a network cable — or give Imager the PitchTribe list instead, which brings the customisation back.

  4. Plug everything in

    1. Push the microSD card into the slot on the underside of the Pi, contacts facing the board, until it’s fully in.
    2. Connect the HDMI cable from the Pi to the TV. On a Pi 5 use the micro-HDMI socket nearest the power socket (marked HDMI0).
    3. If you’re using a network cable, plug it into the Pi’s network socket and the club router.
    4. Switch the TV on and set it to the HDMI input the Pi is plugged into.
    5. Plug in the power supply last. There’s no on/off switch — the Pi starts as soon as it has power.

  5. Wait for the first start-up

    The first start takes longer than usual — allow up to 5 minutes. You’ll see lines of white text, the screen may go black for a while, and the Pi may restart once by itself while it finishes setting up the card. That’s all normal; don’t unplug it.

    When it’s ready, the TV shows the PitchTribe logo and the address of the dashboard:

    From now on, the Pi goes straight to this screen every time the power comes on, so after a power cut it sorts itself out. Leave the Pi switched on: turning it off at the wall every night can, over time, damage the memory card. Switch the TV off instead.

  6. Open the dashboard on your phone

    Connect your phone to the same network as the Pi (the club Wi-Fi), open the web browser and type:

    http://pitchtribe.local

    If you chose a different hostname in step 3, use that instead — for example http://bar-tv.local.

    If the page won’t open, type the address shown at the bottom of the TV instead (it looks like http://192.168.1.50/). Some Android phones and some routers don’t understand .local addresses; the numbers always work.

  7. Name your club and choose a password

    The first time you open the dashboard it asks for your club’s name and an admin password. Choose a password of at least 8 characters and share it only with the volunteers who will manage the screens — anyone with it can change what’s on the TV.

    Tap Create dashboard. Within a second or two the TV changes to a welcome message with your club’s name. That’s it — your screen is working.

    Bookmark it

    Add the dashboard to your phone’s home screen (in the browser’s share or ⋮ menu) so it opens like an app next time.

  8. Put your first notice on the TV

    1. In the dashboard, open Content and tap Notice.
    2. Write a headline and a message — say, this Saturday’s kick-off time — and pick a colour.
    3. Leave Add to playlist set to Main and tap Create.

    The TV now takes turns between the welcome message and your notice. To remove the welcome message, open Playlists → Main and switch it off.

    Photos and videos work the same way: tap Upload on the Content page, then add them in Playlists → Main → Add content. Using the dashboard covers menus, fixtures, live scores, timings and everything else.

What next?

  • Using the dashboard — menus, fixtures, live scores, widgets, and showing things only at certain times.
  • Backing up to a USB stick — do this early: two minutes now saves starting from scratch if the memory card ever fails.
  • Adding more screens — a second TV in the bar, the function room or the changing rooms.
  • Guest Wi-Fi — free Wi-Fi for visitors, with your club’s sign-in page.
  • Troubleshooting — if anything above didn’t go to plan.
