Looking after it

Updates and backups

A PitchTribe screen can run for months untouched. Two things are worth doing now and then: updating the software, and keeping a copy of your content in case the memory card fails.

Both need a terminal on the Pi — see connecting with SSH. That’s why the setup guide suggests setting a username and switching on SSH in Imager.

Updating PitchTribe

Check which version you have in the dashboard under Settings → About, and what’s new on the releases page. To update, connect to the Pi and run the installer again:

curl -sSL https://pitchtribe.media/install.sh | sudo bash

Your content, playlists, screens and password are all kept. The screen goes blank for a moment while PitchTribe restarts.

Using guest Wi-Fi or several screens?

Repeat the options you installed with, or they’ll be left out. For example, on a Pi with guest Wi-Fi: curl -sSL https://pitchtribe.media/install.sh | sudo PITCHTRIBE_PORTAL=1 bash. On an extra screen: … | sudo PITCHTRIBE_SERVER=http://clubhouse.local bash.

Updating Raspberry Pi OS

Raspberry Pi OS gets security fixes regularly. Every few months, connect to the Pi and run:

sudo apt update && sudo apt full-upgrade -y && sudo reboot

The Pi restarts and the screen comes back by itself after a minute or two.

Backing up

Everything that makes your PitchTribe yours — content, uploaded photos and videos, playlists, screens, settings and the password — is in one folder on the Pi, /var/lib/pitchtribe. Copy it somewhere safe after any big change.

  1. Pack it into one file, on the Pi

    Connect to the Pi and run:

    sudo tar czf ~/pitchtribe-backup.tar.gz -C /var/lib pitchtribe && sudo chown $USER ~/pitchtribe-backup.tar.gz

  2. Copy the file to your computer

    Type exit to leave the Pi. Then, in the same terminal on your own computer (Windows, Mac or Linux), run this with your own username and Pi name:

    scp yourname@pitchtribe.local:pitchtribe-backup.tar.gz .

    The file lands in the folder the terminal is in — usually your home folder. Keep it somewhere safe, like the club’s shared drive.

Restoring, or moving to a new card or Pi

  1. Set up the new card

    Follow the beginner’s guide up to step 5, using the same hostname as before and a username with SSH on. You don’t need to set up the dashboard.

  2. Copy the backup to the Pi

    From the folder with your backup file:

    scp pitchtribe-backup.tar.gz yourname@pitchtribe.local:

  3. Unpack it

    Connect to the Pi and run:

    sudo systemctl stop pitchtribe
sudo tar xzf ~/pitchtribe-backup.tar.gz -C /var/lib
sudo chown -R pitchtribe:pitchtribe /var/lib/pitchtribe
sudo systemctl start pitchtribe

    Open the dashboard: your content and password are back, and the TV picks up its playlist again.

Memory cards wear out

A good-quality A2 card in a Pi that runs all day usually lasts years, but cheap cards can fail sooner. A spare card with PitchTribe already on it, kept in the club office, gets you back up in minutes.
