Running your screens

Adding more screens

One dashboard can run as many TVs as you like — the bar, the function room, the changing rooms — each with its own playlist. Here’s how to add them.

How it fits together

One Pi is the main Pi. It holds your content and the dashboard. Every other TV is a screen that shows content from the main Pi over the club network. Whatever you change in the dashboard reaches all the screens at once, and each screen keeps playing its last playlist if the network drops for a while.

The main Pi is usually the first one you set up. Keep it on a network cable if you can, and give it a clear name such as clubhouse.

Option 1: another Raspberry Pi (recommended)

The neatest way: a Pi behind each TV, starting by itself like the first one.

  1. Write a card with its own name

    Follow the beginner’s guide steps 1–5, but in Imager give this Pi a different hostname — for example function-room. Also set a username and password and switch on SSH; you need them for the next step.

    Every Pi needs its own name

    If two Pis are both called pitchtribe, they fight over the address and the dashboard can’t tell their screens apart.

  2. Point it at the main Pi

    When the new Pi has started, connect to it with SSH and run this, replacing clubhouse with your main Pi’s name:

    curl -sSL https://pitchtribe.media/install.sh | sudo PITCHTRIBE_SERVER=http://clubhouse.local bash

    Then switch off the new Pi’s own, unused dashboard:

    sudo systemctl disable --now pitchtribe

  3. Choose its playlist

    The TV restarts its display and shows the main Pi’s content. In the dashboard, open Screens: the new screen is listed under its name. Choose its playlist, and use Identify if you’re not sure which TV is which.

If you installed on plain Raspberry Pi OS rather than from the PitchTribe image, step 2 is simply the same command with PITCHTRIBE_SERVER — there’s no extra dashboard to switch off.

Option 2: a smart TV, PC or tablet

Anything with a modern web browser can be a screen — a smart TV’s built-in browser, a mini PC, an old laptop or a tablet on a stand.

  1. In the dashboard, open Screens. The Add a screen box at the top has a Screen id field and an address.
  2. Type a name for the screen, such as reception. The address updates to match.
  3. Open that address on the TV or computer, and make the browser full screen (usually F11 on a computer).
  4. It appears in the Screens list. Choose its playlist.

The address looks like this:

http://clubhouse.local/player/?screen=reception

Browsers aren’t as dependable as a Pi

Smart TV browsers often go to sleep, show pop-ups or forget the page after an update, and some don’t understand .local addresses (use the main Pi’s IP address instead). For a screen that runs unattended for months, a Pi is worth the money.

Or: completely separate screens

Every Pi set up from the PitchTribe image has its own dashboard. If two TVs are in different buildings and never share content, you can simply leave them as two independent PitchTribes, each with its own address and password. Most clubs find one shared dashboard easier.
