Get your club’s screens running

PitchTribe turns a Raspberry Pi and any TV into a screen for notices, menus, fixtures, live scores and more. You manage it from your phone. These pages take you from a box of parts to a working screen, assuming no technical knowledge at all.

Where to start

Install on Raspberry Pi OS →Your Pi already runs Raspberry Pi OS? One command adds PitchTribe to it. Using the dashboard →Add notices, menus, photos and live scores, build playlists and choose when things show. Troubleshooting →Blank screen, can’t find the dashboard, forgotten password — fixes for the usual problems.

How PitchTribe works, in one minute

There are three pieces:

  • The Raspberry Pi — a small, cheap computer about the size of a pack of cards. It plugs into the back of the TV with an HDMI cable and stays there.
  • The screen — whatever the Pi shows on the TV. It starts by itself every time the power comes on, with no keyboard or mouse.
  • The dashboard — a web page you open on your phone, tablet or laptop while you’re on the club’s network. Anything you change there appears on the TV within a second or two.

Nothing is stored “in the cloud”. Your notices, photos and settings live on the Pi itself, and there is no account to create and no monthly fee.

Getting help

If you’re stuck, check Troubleshooting first. If that doesn’t help, open an issue on GitHub and describe what you see on the TV. If you’d rather not do any of this yourself, we also sell units ready to plug in and fit them on site.
