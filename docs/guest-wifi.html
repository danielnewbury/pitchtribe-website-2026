Running your screens

Guest Wi-Fi

The Pi behind your TV can also give visitors free Wi-Fi. Guests join an open network, see a sign-in page with your club’s logo and terms, tap Connect, and get internet for a set time. It’s optional and switched off until you add it.

How it works

  • The Pi’s network cable goes to the club router and provides the internet.
  • The Pi’s built-in Wi-Fi becomes the guest network. It no longer connects to the club Wi-Fi. For a bigger venue, a USB aerial or ceiling access points reach much further.
  • Guests can reach the internet only — never the club’s own computers, tills, cameras or the PitchTribe dashboard.
  • Each device gets a speed limit and a session length that you choose. Up to 60 devices can join the Pi’s own radio at once, and about 1,000 across the whole guest network with access points.

You need a network cable

Guest Wi-Fi only works when the Pi is plugged into the club router with a cable. If the Pi currently uses Wi-Fi to get online, run a cable to it first.

Switch it on

This part is done once, from a terminal on the Pi. You need the username and password you set in Raspberry Pi Imager, with SSH switched on.

  1. Plug in the network cable

    Connect the Pi to the club router with a cable and check the TV still shows your content.

  2. Connect to the Pi

    Connect with SSH — for example ssh yourname@pitchtribe.local.

  3. Install the guest Wi-Fi add-on

    curl -sSL https://pitchtribe.media/install.sh | sudo PITCHTRIBE_PORTAL=1 bash

    This re-runs the PitchTribe installer with guest Wi-Fi added. Your content and settings are kept. It takes 5–15 minutes.

Didn’t set a username in Imager? The simplest fix is to write a fresh card with the PitchTribe image and a username, then restore your content — see Updates and backups. Or ask us to set it up for you.

Covering a bigger venue

The Pi’s built-in Wi-Fi is a small radio, good for about one room. There are two upgrades, and you can use either or both. The Buy page lists the parts with prices.

Several rooms, a stand, a pitchside barCeiling access points£275 for three, plus fitting

Whichever you use, guests see one network with one name and sign in once. The dashboard’s Wi-Fi page has a Hardware box that shows what the Pi has found and what it’s using, and it updates by itself when you plug something in or take it out.

A USB Wi-Fi aerial

  1. Plug the Alfa adapter into one of the Pi’s blue USB ports (the blue ones are the fast USB 3 ports). Use a 2 m extension lead so the adapter can sit up high, clear of the TV and any metal. Point the aerials straight up.
  2. In the dashboard, open Wi-Fi. Under Coverage, leave Broadcast from on Automatic — it uses the USB aerial whenever one is plugged in — or choose USB Wi-Fi aerial.
  3. Choose the Band: 2.4 GHz reaches further and through walls; 5 GHz is faster but shorter range. Most clubs want 2.4 GHz for a terrace or car park.
  4. Tap Save. After a few seconds, the Hardware box shows the USB aerial as Broadcasting guest Wi-Fi.

Other USB Wi-Fi adapters may work if Linux supports them as a hotspot (“AP mode”), but the Alfa AWUS036ACM is the one we recommend.

Ceiling access points

Access points are small Wi-Fi radios for ceilings and walls, each cabled back to the Pi. Phones hop from one to the next as people walk around, without signing in again. You need a USB network adapter for the Pi, a PoE switch (it powers the access points through their network cables, so they need no socket), and the access points.

  1. Set up each access point first

    Before connecting them to the Pi, plug each access point into the club router (with the PoE switch, or the power adapter if it came with one) and set it up with the maker’s app — for TP-Link Omada, the free Omada app in standalone mode, no subscription. Give each one:

    • a Wi-Fi network with exactly the same name as in the PitchTribe dashboard, and no password (open) — the sign-in page is the gate;
    • client isolation switched on, so guests can’t see each other’s phones. On Omada this is under the network’s advanced settings. If the model has a “Guest network” switch instead, try that, but if guests then can’t get the sign-in page, turn it off and use client isolation;
    • a different channel from its neighbours on 2.4 GHz — 1, 6 and 11 — so they don’t interfere;
    • its own router and DHCP features off (plain access point mode). The Pi hands out the addresses.

  2. Cable it up

    Plug the USB network adapter into a blue USB port on the Pi, and run a cable from it to the switch’s ordinary port (on the TL-SG1005P, port 5). Plug the access points into the powered ports (1–4). The Pi’s own network port stays connected to the club router — that’s the internet.

    Keep the two networks apart

    Nothing from the club’s own network should be plugged into the access points’ switch, and the switch must not be connected to the club router. The Pi sits between them and is the only way through.

  3. Switch them on in the dashboard

    On the dashboard’s Wi-Fi page, under Coverage, tick Ceiling access points and tap Save. The Hardware box shows the USB network adapter as Access points — cable connected.

    The Pi’s own radio keeps broadcasting too, which is handy for the room it’s in. If the access points cover everything already, set Broadcast from to None — access points only.

Collecting email addresses

If you ask for emails, guests also see a separate box asking whether you may contact them. It is never ticked in advance, as UK and EU law requires. On the Wi-Fi page you can download the list as a spreadsheet (CSV), which shows who agreed, or delete it.

  • Only send marketing to people who ticked the box.
  • Say in your terms what you’ll use the addresses for.
  • Delete the list when you no longer need it.

If guests can’t connect

  • The network doesn’t appear: check Guest Wi-Fi on is ticked and the Status box says the service is running. Look at the Hardware box for warnings — for example a USB aerial chosen but not plugged in. Try a different radio channel.
  • Fine near the Pi, nothing further away: that’s the built-in radio’s range. See Covering a bigger venue.
  • Phones on an access point get no sign-in page: check the access point’s own router/DHCP is off and its “guest network” setting isn’t blocking the Pi (use client isolation instead), and that the Hardware box says the cable is connected.
  • It connects but the sign-in page doesn’t appear: open any web page — http://neverssl.com is a good one — and the sign-in page should load.
  • Signed in but no internet: check the Pi’s network cable, and that the club router itself is online.
